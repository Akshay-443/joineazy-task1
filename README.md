# Assignment Dashboard

A React + Tailwind project with Student/Admin views.

## 🚀 Live Demo
[View on Netlify](https://joyful-pasca-db1540.netlify.app)

## 📌 Features
- Student assignment submission
- Admin assignment creation
- Role switching between Student and Admin
- Tailwind CSS styling

## 🛠 Tech Stack
- React 19
- Tailwind CSS
- Node.js 18
- Netlify (deployment)

## ⚡ Getting Started
Clone the repo and install dependencies:
```bash
git clone https://github.com/yourusername/assignment-dashboard.git
cd assignment-dashboard
npm install
npm start
